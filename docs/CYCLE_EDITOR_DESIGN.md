# 循环编辑器 UI 重设计方案

> 2026-05-29 · 已实施

## 背景

旧版循环编辑器使用表格行 + 展开条件的方式，用户无法直观理解执行顺序和条件分支。

## 新设计：横向泳道 + 卡片流

### 视觉结构

```
┌─ Phase 1 · 全部释放 ──────────────────────────────────────────┐
│                                                                │
│  ┌──────────┐      ┌──────────┐      ┌───────────────┐        │
│  │ ① 技能A  │  ➜   │ ② 技能B  │  ➜   │ ＋ 添加技能    │        │
│  │ 🔑 键:1  │      │ 🔑 键:2  │      └───────────────┘        │
│  │ 👁 像素  │      │  无条件   │                               │
│  └──────────┘      └──────────┘                               │
│   [双击编辑]    [拖拽可排序]                                    │
└────────────────────────────────────────────────────────────────┘
                              │
                              ↓  全部释放后
┌─ Phase 2 · 都未就绪 ──────────────────────────────────────────┐
│  ┌──────────┐  ┌──────────┐  ┌──────────┐                     │
│  │ ① 技能4  │  │ ② 技能5  │  │ ③ 技能6  │                     │
│  │ 👁 CD灯  │  │ 👁 CD灯  │  │ 👁 CD灯  │                     │
│  └──────────┘  └──────────┘  └──────────┘                     │
└────────────────────────────────────────────────────────────────┘
                              │
                              ↓  都未就绪后
┌─ Phase 3 · 每次执行 ──────────────────────────────────────────┐
│  ┌──────────┐                                                  │
│  │ ① 技能2  │                                                  │
│  │ 👁 形态点 │                                                  │
│  └──────────┘                                                  │
└────────────────────────────────────────────────────────────────┘
                              │
                              ↓  🔄 循环重置
```

## 组件架构

```
CycleEditorPage.vue
├── EngineControlBar.vue        ← 启停按钮
├── PhaseLane.vue × N           ← Phase 泳道
│   ├── SkillCard.vue × N       ← 技能卡片
│   │   ├── 优先级徽章 (① ② ③)
│   │   ├── 技能名
│   │   ├── 触发键
│   │   └── 条件图标 (👁/📊/🔗/—)
│   ├── ➜ 箭头 (优先级顺序)
│   └── ＋ 添加按钮
├── SkillEditModal.vue          ← 双击编辑弹窗
│   └── ConditionBuilder.vue    ← AST 条件编辑器
└── ExecLogViewer.vue           ← 执行日志
```

## 文件清单

| 文件 | 说明 |
|---|---|
| `src/views/CycleEditorPage.vue` | 主页面，Phase 管理 + 保存 |
| `src/components/editor/PhaseLane.vue` | Phase 泳道：头部配置 + 卡片列表 |
| `src/components/editor/SkillCard.vue` | 技能卡片：优先级 + 名称 + 条件图标 |
| `src/components/editor/SkillEditModal.vue` | 双击编辑弹窗：技能选择 + 条件编辑 |
| `src/components/editor/ConditionBuilder.vue` | AST 条件表达式编辑器（已有） |

## 条件图标映射

| AST 类型 | 图标 | 颜色 | tooltip 示例 |
|---|---|---|---|
| `pixel_skill` / `pixel_point` | 👁 | 蓝 `#2080f0` | 技能像素 sk1 tol=20 |
| `skill_metric_ge` | 📊 | 绿 `#18a058` | success >= 3 |
| `and` / `or` / `not` | 🔗 | 橙 `#f0a020` | AND(2) |
| `null`（无条件） | — | 灰 | 无条件 |

## Phase 完成条件

| 值 | 标签 | 行为 |
|---|---|---|
| `all_fired` | 全部释放后 | 所有技能都至少打过一次 |
| `any_fired` | 任一释放后 | 有一个打过就完成 |
| `none_ready` | 都未就绪后 | 没打的技能全都不就绪时完成 |
| `always` | 每次执行后 | 打一个立刻完成 |

## 交互方式

- **双击卡片** → 弹出 SkillEditModal 编辑器
- **Phase 头部折叠** → 收起/展开卡片区域
- **＋添加技能** → 在当前 Phase 末尾新增空卡片
- **删除 Phase** → 右上角垃圾桶按钮 + 确认弹窗
- **保存** → 顶部保存按钮，通过 IPC 保存完整 Profile，后端持久化为 TOML

## 未来可扩展方向

- Phase 之间拖拽调换顺序
- Phase 内卡片拖拽排序（优先级）
- Phase 间分支跳转（switch_mode 等网关动作）
- 条件表达式的节点化可视化（类似 Blueprint）
